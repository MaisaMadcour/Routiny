# Routiny — Privacy Policy

This repository hosts the public privacy policy page for the **Routiny** app
(Android and iOS), served with GitHub Pages from the `docs/` folder:

https://maisamadcour.github.io/Routiny/

This URL is registered in the Google Play listing and in App Store Connect,
so the repository must stay public and `docs/index.html` must keep its path.

The app's source code lives in a private repository.
